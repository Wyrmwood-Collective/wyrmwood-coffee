## Development Setup

Install `uv` and clone the repository:

```shell
winget -e --id=astral-sh.uv
git clone git@github.com:bverble-catalyte/wyrmwood-coffee.git
```

Run the development server:

```shell
uv run dev
```

Run test suite:

```shell
uv run pytest
```
